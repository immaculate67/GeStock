UMA OPERAÇÃO MAIS CLARA

Tudo ligado ao seu inventário.

Da entrada de produtos ao fecho da venda, acompanhe o que acontece e saiba o que precisa de atenção.

01

Produtos e stock

Organize referências, categorias, fornecedores e níveis mínimos. Registe entradas, saídas e correções com histórico.

Vendas

Registe vendas com quantidades e preços históricos. O stock acompanha cada operação e as respetivas anulações.

03

Consulte receitas, artigos mais vendidos, valor de inventário e alertas de reposição.

SOBRE O PROJETO

Feito para simplificar
o dia a dia.

O GeStock é uma aplicação de gestão para pequenos negócios, construída com PHP, SQLite, HTML, CSS e JavaScript.

Esta página é uma apresentação estática. O GitHub Pages não executa PHP nem disponibiliza a base de dados da aplicação. Para utilizar o painel com dados reais, é necessário executar o projeto num servidor com PHP.
